## powershell-scripts
A centralized repository containing PowerShell scripts and operational automation tools.

## Repository Structure

- `active-directory/` - User management, group policy, and AD health routines.
- `auditing-and-scanners/` - Hardware, software, and compliance reporting scripts.
- `maintenance/` - System cleanup, update management, and disk utility scripts.
- `software-management/` - Software deployment and removal packages.

## Guidelines & Security

> **Note:** Never commit hardcoded API keys, domain passwords, or sensitive enterprise data. Always use parameters or environment variables for credentials.

## Prerequisites

- PowerShell 7.x+
